# openapi (EXPERIMENTAL)

ScannerApp es una aplicación institucional desarrollada para la Corporación Universitaria Minuto de Dios, cuyo objetivo principal es gestionar el control de ingreso de los estudiantes a espacios específicos dentro del campus universitario, como la Biblioteca y el Gimnasio.

El sistema registra de manera precisa cada entrada realizada por los estudiantes, permitiendo a los administradores llevar un monitoreo detallado del uso de estas instalaciones. Esta trazabilidad facilita la generación de reportes, el análisis de patrones de asistencia y la optimización de recursos en función del uso real de los espacios.

Además, ScannerApp ha sido diseñado con una interfaz moderna, intuitiva y segura, que se adapta a los flujos de trabajo institucionales y promueve una gestión eficiente y automatizada de los accesos. Su implementación fortalece la organización interna, mejora la experiencia del estudiante y contribuye al cumplimiento de las políticas de control y seguridad establecidas por la universidad.
